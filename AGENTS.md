## Agent skills

### Issue tracker

Issues and specs live as local Markdown files under `.scratch/<feature>/`. Before creating, reading, or updating them, read `docs/agents/issue-tracker.md`.

### Triage labels

Use the five default triage roles as local issue states. Before assigning a triage state, read `docs/agents/triage-labels.md`.

### Domain docs

Single-context layout: root `GLOSSARY.md` and `docs/adr/`. Before exploring the codebase, read `docs/agents/domain.md`.
